# 1211 — one truth, one place (12 Nov 2026)

Owner, 12 Nov: "the optimizer should look at whether every source of truth is centralised — only one place, never two
places holding the same truth, because that makes editing harder." The Optimiser already had three narrow cousins
(`in-sync` copied name columns, `one-place` business jobs, `dup` copied code). `tools/one-truth.js` adds the general
family, three ratios over natural units, no weights (1210):

- `truth-facts` — distinct facts (a literal list of 3+ values, or an object of 3+ plain settings, with a word in it)
  across js/, backend/, tools/, check/, index.html and data/settings/; followed = written in one file.
- `truth-lists` — literal lists naming 3+ served files (backend/files.json's or index.html's FILES); followed = the
  source itself, a data/settings switch (a subset with its own meaning), or a generated copy.
- `truth-labels` — app and backend ids given a user-visible name; followed = the same words are not written for that
  id in two files (two different names may be two different things, so only a copied name is an offence).

**A generated copy is one truth**: a file headed WRITTEN/GENERATED BY tools/…, a `(generated)` … END block
(tools/permissions.js), or a line tools/tiers.js rewrites (read off its own `want` table, so the rule keeps no copy).

**Why the backend lists mattered.** check-columns, check-rows, check-dead, check-gas-load and check/live.js each named
the backend files by hand; when doPost and doGet were cut into post-*.gs and get-*.gs (1130, 1140) and bizchecks,
workfile, inbox, push, sync were added, most of those lists were never told. All five now read backend/files.json
through `tools/file-lists.js` (`gsFiles`, `gsSource`). Scanning the files they had missed surfaced: a read of
`applications.handle`, a column that tab has never had (post-admin.gs, now `''` — what it always returned); the
old-row `person_name` fallback, allowed by check-columns but not check-rows (now one list, `OLD_READS` in
file-lists.js); two non-row fields (`ring.learn`, `who.fail`) check-columns took for columns; and check-dead's comment
stripper eating `'https://…' + thisScriptId_()` as a `//` comment. check-strings named 54 of the 104 app files; it
reads FILES now (`appFiles`), and its data-do tag match no longer runs across lines into a regex.

**Other fixes**: `SOON_WIDGET_NAMES` (find-finder.js) is written by tools/tiers.js from map.js's WIDGETS (map.js is a
LATER file, so Find still needs the names before it loads); Settings' "(Kids settings)" labels in layout.js read
TABS_BUILT; the three describing-word fields are `ADJECTIVE_FIELDS` (me-shelves.js), read by me-settings and me-card.

Before → after: truth-facts 5074/5191 → 5068/5182, truth-lists 6/19 → 6/13, truth-labels 265/288 → 285/288.
