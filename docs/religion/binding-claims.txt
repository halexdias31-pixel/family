RED-TEAM (strong Muslim = SM, neutral philosopher = NP)
 R1 (a) SM: "Your Church binds the whole Bible as inspired, so every historical detail."
    Facts: Jerusalem 1672 (Dositheus) Decree 2 calls Scripture God-taught and the Church infallible; it is a local synod, later edited by Dositheus himself, not an ecumenical definition; Trullo c.2 fixes canon sources, not inerrancy; no ecumenical council defines detailed historical inerrancy.
    Verdict: JUDGEMENT. Inspiration is binding; detail-inerrancy is not conciliarly defined, but Dositheus' language and patristic usage give SM a real foothold. If it binds (¬P6), Z3 shows T fails.
 R2 (b) NP: "Convenient vagueness: you avoided defining so you can't be falsified."
    Reply: the Creed's "under Pontius Pilate" is a dated, public, falsifiable anchor (a historical person, ~26-36 AD); crucifixion, death and burial are checkable and pass.
    Verdict: PARTLY CLOSED / JUDGEMENT. The anchor is real, but the binding set is small; a small set passing is weaker evidence than a large set passing. Compare: Sunni set is larger by design. Asymmetry of exposure is acknowledged, not removed.
 R3 (c) SM: "History excludes miracles; 4:157 is a miracle, so history can't judge it."
    Reply: the 'made to appear' (shubbiha) is a miracle, but its checkable consequence — Jesus did not die on a Roman cross — is a historical claim; history judges the outcome, not the mechanism. Same rule applied to the Resurrection (excluded) vs. death/burial (judged).
    Verdict: CLOSED for the death claim; SM may hold that a miracle can produce false historical appearance — that is unfalsifiable and equally available to any side, so it does not break symmetry.
 R4 (d) SM/NP: "Sunni ijma' is not a binding body like councils."
    Reply: P2 rests on stated consensus (Qadi Iyad, al-Shifa; Nawawi) that knowing denial of an agreed verse is kufr — the bindingness is of the Qur'an text itself, stronger than a council. For raised-alive/return, consensus is claimed (Ibn Atiyya; Ibn Hajar: mutawatir) but modern dissent exists (e.g. Ghamidi).
    Verdict: CLOSED for 4:157 text being binding; JUDGEMENT for the consensus reading (feeds R6).
 R5 (e) NP: "The Orthodox Church also binds liturgical/hagiographical claims."
    Reply: liturgical texts and saints' lives are not dogmatic definitions; Orthodox writers routinely accept that synaxaria contain legend. But lex orandi carries weight, and e.g. Dormition narratives are prayed.
    Verdict: JUDGEMENT. Dormition is miraculous (excluded); no clearly historical liturgical item is shown to be binding AND contradicted. OPEN if one is found.
 R6 (f) SM: "4:157 can be read without denying death (Ahmadi swoon; 'they did not kill him' = did not defeat him; Todd Lawson / some modern readings)."
    Verdict: CLOSED for Sunni mainstream (classical tafsir Tabari, Ibn Kathir: substitution, Jesus raised alive; Ahmadi reading is rejected by Sunni authorities). JUDGEMENT whether consensus on the reading equals consensus on the verse; Z3 (f) shows T needs P3.
 R7 (g) SM: "Tu quoque — both affirm OT events (Moses, Pharaoh, Flood); if those fail, both fail."
    Verdict: CLOSED conditionally: under P6 the Orthodox side is not bound to OT detail; the Qur'an's own versions (e.g. Pharaoh drowned with Haman, global-scale flood with Noah) are bound under P2. Symmetry is broken only through P6, so R7 reduces to R1.
 Other Sunni items: Haman with Pharaoh = DISPUTED (anachronism vs. Esther; apologetic Egyptian 'hmn' claim contested). Mary 'sister of Aaron' = NOT CONTRADICTED (idiom of lineage; Sahih Muslim 2135 hadith gives this reading). Raised alive/return = miracle, EXCLUDED.
