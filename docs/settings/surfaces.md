# surfaces

| id | area | kind | rule | because | source | active |
|---|---|---|---|---|---|---|
| SF-01 | Surfaces | rule | NO POP-UPS. Nothing opens in a new tab, a new window, or a browser dialog. Ever. | All three take the page away from the person. A tab needs pop-up permission, so the first press often does nothing at all; the back gesture then leaves the app entirely and whatever was filtered or half-filled in is gone. | decided | TRUE |
| SF-02 | Surfaces | rule | No alert(), confirm() or prompt(). There are none left in the codebase. | A browser dialog is an OS dialog: the OS's typeface, the OS's buttons, and not one word this app chose. On a phone it reads as the page having been taken over by something else. | js — 4 confirms and 2 prompts removed | TRUE |
| SF-03 | Surfaces | rule | ASKING A YES-OR-NO QUESTION: the button becomes the question. First press changes its words, second press does the thing, four seconds of nothing puts it back. | It says what will happen in the app's own words, and a stray tap cannot leave a control armed. `sure_()` in receipt.js. | receipt.js sure_ | TRUE |
| SF-04 | Surfaces | rule | ASKING FOR A VALUE: a sheet with a real field, never a dialog. | A sheet can explain why the answer matters — "this goes in the event log and is the whole audit trail" — which a one-line grey box cannot. It was also the only place a value was typed into something the app did not draw. | receipt.js askHow_ | TRUE |
| SF-05 | Surfaces | rule | SHOWING SOMETHING LONG — a paper, a document, a receipt: the sheet. It is part of this page, so closing it puts you back exactly where you were. | Printing still works: a sheet is in the document, so the browser's own print takes it. The tab was never what made that possible. | resource.js, terms.js | TRUE |
| SF-06 | Surfaces | rule | A WIDGET OPENS INSIDE ITS OWN CARD, in the slot the card already carries. It does not open over anything. | The thing a widget opened was never a description of the tool, it WAS the tool — so a panel added nothing but a lid. | tiles.js widgetTiles_ | TRUE |
| SF-07 | Surfaces | rule | A TOAST IS THE ONLY THING THAT APPEARS UNASKED, and it never asks for anything or blocks anything. | It reports what already happened. Nothing waits on it and nothing is lost if it is missed. | shell.js toast | TRUE |
| SF-08 | Surfaces | rule | AN EXTERNAL LINK IS THE ONE EXCEPTION, and only where the destination is genuinely another website. | Somebody's bank is not this app and should not pretend to be. Everything that belongs to @family. opens here. | find.js link cards | TRUE |
