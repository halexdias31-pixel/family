Verse screen

Use Chrome on a Chromebook or computer (not a phone).

  1. 1 Plug the screen into the Chromebook.
  2. 2 Press Install and choose the screen.
  3. 3 Type your Wi-Fi name and password.

If it doesn't show up: try another cable, or hold the BOOT button while you plug it in. To change the Wi-Fi, do it all again. Free software (GPL-3.0); the source is in tools/epaper-verse/.
