# data/race-map.json — map data licence

The Colliers Wood racer's map (`data/race-map.json`, written by `tools/race_map.py`) is derived from
OpenStreetMap: roads, the River Wandle, parks, land use, buildings and named landmarks.

Map data © OpenStreetMap contributors, available under the Open Database Licence (ODbL) 1.0:
https://www.openstreetmap.org/copyright — https://opendatacommons.org/licenses/odbl/1-0/

`data/race-map.json` is a Derivative Database under the ODbL and is offered under the same licence.
Heights are the `dem` the file names. EU-DEM v1.1 via OpenTopoData (produced using Copernicus data and information
funded by the European Union — EU-DEM layers, © European Environment Agency); or Copernicus GLO-90 via Open-Meteo
(© DLR e.V. 2010-2014 and © Airbus Defence and Space GmbH 2014-2018, provided under COPERNICUS by the European Union
and ESA). Where OSM has no height, roof or colour for a building, the file holds a typical London value instead,
marked as such in that building's row (docs/history/511).
